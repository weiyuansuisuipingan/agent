# 可直接填写的申报文案

我主导设计并实现了一个面向企业销售、法务、财务协同场景的“合同审查与回款风险预警 Agent”。它解决的核心痛点是：业务合同提交后，法务通常需要逐条核对付款周期、验收条件、自动续约、责任边界、知识产权归属、数据合规等高风险内容，人工审查耗时长、标准不一致，而且历史项目中的风险经验难以复用，直接影响签约效率和回款安全。

在核心逻辑上，这个系统采用了多 Agent 协作。首先由文档解析 Agent 对合同文本进行结构化抽取，识别账期、验收期、续约条款、责任上限、IP 归属和数据跨境等关键字段；然后由条款比对 Agent 将抽取结果与标准模板、规则库进行逐项比对；接着由风险推理 Agent 做长链路分析，识别“长账期 + 长验收 + 自动续约”这类复合风险，以及“无限责任 + IP 归属客户”这类收益与风险失衡问题；最后由报告生成 Agent 输出风险分级、修改建议、人工复核建议和结构化审查报告。

当前我已经完成了可运行的 MVP，并沉淀出可复用的项目结构、规则逻辑和样例合同。该方案能够将原本依赖人工的重复审查工作前移到自动化流程中，帮助团队更快筛出高风险合同，把法务精力集中在真正复杂的交易判断上。若在企业内部落地，预计可将单份合同的初审时间从 1 小时以上压缩到 10 到 15 分钟，并显著提升风控一致性与回款效率。
