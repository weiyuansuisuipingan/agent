# 项目说明：合同审查与回款风险预警 Agent

## 1. 项目定位

这是一个面向 B 端业务流程的 AI Agent 项目，目标不是生成聊天内容，而是进入企业真实协作链路，帮助销售、法务、财务更快完成合同风险审查。

它聚焦一个很实际的问题：企业合同审查往往依赖人工逐条阅读，既慢，又容易受个人经验影响。很多风险并不是单一条款就能看出来，而是多个条款组合后才会放大，比如“长账期 + 长验收 + 自动续约”，这会直接影响签约节奏、收入确认和回款安全。

## 2. 核心痛点

- 合同审查流程长，业务方等待时间高
- 审查标准依赖资深法务经验，难以规模化复制
- 常见风险可以识别，但复合风险经常遗漏
- 历史争议无法持续沉淀到新项目中

## 3. 核心逻辑流

### 阶段一：文档解析

`DocumentParserAgent` 负责读取合同文本，抽取付款周期、验收周期、自动续约、责任边界、知识产权归属、数据跨境等结构化字段。

### 阶段二：规则比对

`ClauseComparisonAgent` 将抽取结果与公司标准合同规则库比对，识别明显偏离红线的条款。

### 阶段三：长链路推理

`RiskReasoningAgent` 不只判断单个条款是否危险，还会对多个信号进行组合推理。例如：

- 长账期 + 长验收周期 -> 现金流链路风险
- 无限责任 + IP 归属客户 -> 收益与风险失衡
- 数据跨境 + 成果归属客户 -> 合规复合风险

### 阶段四：报告交付

`ReportAgent` 输出 Markdown 报告和 JSON 摘要，让业务方能快速读结论，系统方也能将结构化数据继续接入审批流或知识库。

## 4. 为什么这个项目有价值

- 它贴近真实企业场景，容易让评审理解业务意义
- 它体现了 Agent 不只是“问答”，而是“多角色流程协同”
- 它展示了长链路推理能力，而不是简单关键词命中
- 它天然具备可扩展性，后续可以接入 OCR、向量检索、历史案例库、审批系统

## 5. 当前实现范围

当前版本是一个可运行 MVP，包含：

- 本地文本合同解析
- 规则引擎
- 多 Agent 串联
- 风险评分
- 审查报告自动生成
- 高风险与低风险样例合同

## 6. 可继续扩展的方向

1. 接入 PDF / DOCX 解析
2. 将规则库改造成可配置 YAML 或数据库
3. 叠加 LLM 推理增强复杂条款理解
4. 接入企业审批流，自动创建法务工单
5. 引入历史争议案例检索，增强建议质量
