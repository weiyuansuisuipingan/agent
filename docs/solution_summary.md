# 项目摘要

## 项目名称

合同审查与回款风险预警 Agent

## 项目简介

这是一个面向企业销售、法务、财务协同场景的多 Agent 合同审查系统。它的目标是将合同初审中的重复性工作前移到自动化流程中，帮助团队更快识别付款周期过长、验收条件模糊、自动续约、无限责任、知识产权归属异常、数据跨境等高风险条款，并输出结构化审查结果。

## 解决的问题

- 人工审查耗时长，业务等待时间高
- 审查标准容易受个人经验影响，结果不稳定
- 风险经验难以复用，历史案例沉淀不足
- 复合风险不容易在单次人工浏览中被及时识别

## 系统流程

1. `DocumentParserAgent` 负责解析合同文本并抽取关键字段
2. `ClauseComparisonAgent` 负责根据标准规则识别单点风险
3. `RiskReasoningAgent` 负责组合多个信号，识别现金流、合规、责任等复合风险
4. `ReportAgent` 负责生成 Markdown 报告和 JSON 摘要

## 当前实现

当前版本提供了一个本地可运行 MVP，包含：

- 合同文本解析
- 风险规则引擎
- 多 Agent 串联处理流程
- 风险评分与人工复核建议
- 示例合同与自动生成报告

## 可扩展方向

1. 支持 PDF / DOCX 解析
2. 将规则库改造成配置化结构
3. 接入历史案例检索与向量搜索
4. 引入大模型增强复杂条款理解
5. 接入审批系统或法务工单系统
